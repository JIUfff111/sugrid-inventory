# SUGRID Server Manager

Windows desktop manager prototype using Tauri 2, React, TypeScript, Vite, Fluent UI, and Lucide.

The current sample uses mock data only. Buttons demonstrate screen states and do not inspect or change Windows processes, Git, the inventory database, or local files.

## Preview

Run npm install, then npm run dev. The Vite preview uses port 3007.

## Checks

- npm run lint
- npm run typecheck
- npm test
- npm run build

Native Tauri development and NSIS packaging require Rust and Microsoft C++ Build Tools on Windows.
