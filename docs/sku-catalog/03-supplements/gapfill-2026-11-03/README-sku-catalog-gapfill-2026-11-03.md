## 增量是怎么算出来的

以 `_backup-2026-11-03/` 里的补充前快照为基线做 diff：当前调研 JSON 中不在基线内的型号与配置组合即为本次新增。可复现、可核对，不是手工统计。

```bash
cd web/docs/sku-catalog
python ../../scripts/sku-catalog/build_supplement_by_brand.py
```

脚本会自动重建 `分品牌/` 五份工作簿、五组 CSV 和汇总表。

## 口径速查

- **置信度**：high = 厂商官方页 / PSREF 产品页 / 产品库规格页；medium = 媒体报道、百科、系列汇总页。本批补的 912 条里以 high 为主。
- **不做笛卡尔积**：一行配置必须能追到实际销售的搭配。
- **待核实不等于没查**：271 条都写了具体原因和建议路径（例如"PSREF 已下架，需查联想商城历史页"）。
- **只收能验证的**：官网反爬（戴尔 support、微星官网返回 403）或只有 PDF 手册的型号，一律不放主表。
