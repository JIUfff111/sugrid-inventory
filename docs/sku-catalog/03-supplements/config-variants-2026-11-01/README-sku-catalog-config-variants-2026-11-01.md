## 4. 口径

- 字段统一：`cpu` 去掉「英特尔酷睿 / AMD 锐龙 / Intel Core」等前缀，只留型号；`gpu` 统一为「集成显卡」或「RTX 3060 6GB 笔记本电脑 GPU」；`storage` 统一「512GB SSD」；`ram` 统一「16GB」。
- 只收真实销售过的组合，不做 CPU×显卡 的笛卡尔积；每条都有独立来源。
- 同一型号内五元组不重复。
