## 3. 口径

- 字段格式统一：`cpu` 如「i7-12700H」「R7-5800H」，`gpu` 如「RTX 3060 6GB 笔记本电脑 GPU」，`ram`「16GB」，`storage`「512GB SSD」，`screen`「16英寸 2560x1600 165Hz」。
- 只收真实销售过的组合，不做 CPU×显卡 的笛卡尔积；每条配置都带独立来源链接。
- 同一型号内五元组不重复；跨型号也不合并。
- 补录重点放在 CPU 与显卡差异上，同配置换内存/硬盘的情况只保留实际在售的版本。

439 条配置的置信度：high 214、medium 184、**low 41**。

- low：百科、整理帖，或来源页对脚本访问受限但浏览器可打开的页面。
