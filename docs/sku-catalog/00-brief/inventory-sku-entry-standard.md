# 库存 SKU 录入与展示标准

本标准用于采购 SKU 型号目录、采购录入选择器、库存机器配置摘要及库存标签。资料交付保留来源中的正式配置描述；系统界面按本标准显示简短标签。

## 型号字段

- 型号记录按「产品类型 + 品牌 + 型号 + 型号年份」区分。
- 品牌、型号和年份分别存放。完整展示应包含品牌和年份，例如 `ThinkPad X13 2020`；不要把年份重复放入型号主体。
- 游戏本属于「笔记本电脑」类型，保留其具体品牌型号，不另外建立「游戏本」类型或型号分类。
- 小米与 Redmi / 红米归为「小米」品牌组；型号系列名仍使用资料中的正式名称。

## 配置录入与显示

配置值须有来源依据。SKU 型号目录和交付表保留来源中的 CPU、显卡、屏幕完整信息供核验；界面和新增库存机器使用以下统一短格式：

| 字段 | 录入/显示规则 | 示例 |
| --- | --- | --- |
| CPU | Intel Core 去掉 Intel/Core 前缀；AMD Ryzen 去掉 AMD/Ryzen 前缀并将系列写为 R；Core Ultra 保留 Ultra 系列名。保留有来源依据的代际和型号。 | `Intel Core i5-10210U` → `I5-10210U`；`AMD Ryzen 5 PRO 4650U` → `R5-4650U`；`Intel Core Ultra 7 155H` → `Ultra 7 155H` |
| 独立显卡 | 去掉 NVIDIA、GeForce、AMD Radeon 等厂商/系列冗余前缀、显存容量、GDDR 标记和「笔记本电脑 GPU」等用途描述，只保留显卡型号。 | `NVIDIA GeForce RTX 4060 8GB GDDR6 笔记本电脑 GPU` → `RTX 4060`；`AMD Radeon RX 6800M 12GB` → `RX 6800M` |
| 集成显卡 | 界面统一显示为 `集显`，不显示 UHD、Iris Xe、Radeon 780M 等冗长集显名称。SKU 来源资料仍保留实际芯片名称。 | `Intel UHD Graphics 620` → `集显`；`AMD Radeon 780M` → `集显` |
| 屏幕 | 界面只显示分辨率等级；省略屏幕尺寸、刷新率、色域、亮度和面板营销描述。型号目录继续保留这些来源细节。 | `16 英寸 2560x1600 165Hz 100% sRGB 500 nits` → `2.5K` |

## 手工 SKU 目录

- 手工录入使用独立的「手工 SKU 库」，与内置 SKU 目录分表维护、分开查询，不把手工建档写入内置库。
- 采购手工录入时，品牌和型号必须从手工 SKU 库下拉选择，不允许在录入表单自由输入；型号档案包含产品类型和年份。
- 需要新增品牌或型号时，先由管理员在「设置 → 手工 SKU 库」建档，再回到采购手工录入选择。
- 手工 SKU 入库时用 `manualSkuId` 关联手工档案，不自动匹配同名内置 SKU；配置仍按本标准写入单台机器快照。
- 已被采购记录引用的手工 SKU 不物理删除；停用或移出可选列表后仍保留历史关联。已使用型号的品牌、型号、年份不可改名，需停用旧档并新建。

屏幕分辨率按像素映射：约 `3840` 及以上显示 `4K`；`3150–3799` 显示 `3.2K`；`3000–3149` 显示 `3K`；`2800–2999` 显示 `2.8K`；`2500–2799` 显示 `2.5K`；`2100–2499` 显示 `2K`；`1920x1200` 级显示 `FHD+`；`1920x1080` 级显示 `FHD`；`1280` 级显示 `HD`。无法识别分辨率时显示 `规格待核实`，不得猜测。

## 数据保护

- 简短标签是展示、内置目录种子和单机录入格式；官方来源文本、交付工作簿和来源链接继续保留在 `01-deliverables/`，不被短格式覆盖。
- 新采购的单机配置按界面短格式写入库存机器配置，保证库存查询、销售追溯和标签打印一致。
- 格式化和去重后相同的显示选项只呈现一次；选择结果仍绑定到原 SKU 选项。
- 来源缺少明确配置时保持缺失并标记待核实，不通过显示规则补造型号或规格。
